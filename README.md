# Slop Vallromanes

Vallromanes (Vallès Oriental, Barcelona, Catalonia) in 3D, built from official survey data and rendered in the browser with [three.js](https://threejs.org/), WebGPURenderer and TSL. Explore the municipality on foot, by car, by bicycle or by helicopter: its real terrain, about 2,900 buildings and 4,300 structures with their real heights, floors and roofs, 38 km of streets with their names, stairs, walls, hedges, pools, street lamps and some 130,000 trees in its woods, with cars and people going about, synthesised sound, a map, a list of places to teleport to, and the sun of 41.5° N. The town hall, the church of Sant Vicenç, the two schools and Can Poal have their own look.

It is a fork of [mrdoob/slop-newyork](https://github.com/mrdoob/slop-newyork): the rendering, lighting, camera, controllers and post-processing come from there, and the town is baked offline from open data instead of generated.

## Run it

You need a browser with WebGPU (Chrome, Edge or a recent Safari). The game is plain ES modules with no build step, and the whole download is about 6.4 MB gzipped:

```bash
npx serve .      # then open http://localhost:3000
```

Add `?notraffic`, `?nowoods` or `?notrees` to the address to leave out the cars and people, the woods or the surveyed trees.

Controls: `W A S D` move, `Shift` boosts, `Space` jumps or climbs, `1`–`4` switch between walking, driving, cycling and flying, `V` or `5`–`0` change camera, `M` opens the map, `H` hides the HUD, `N` mutes the sound. The map teleports where you click.

## Rebuild the data

The runtime data in `data/` is generated by the scripts in `tools/vallromanes/` and committed. To rebuild it you need the raw downloads in `tools/data/vallromanes/raw/` (not committed):

```bash
npm install
npm run inventory   # report on the raw BUE shapefiles
npm run geodata     # boundary, roads, stairs, terrain, buildings, features, props, canopy, labels -> data/
npm test
```

`node tools/vallromanes/fetch-icgc-dtm.mjs` downloads the LiDAR terrain and surface models for the municipality (run it with `--product dsm --level 0` for the surface model, which gives the woods and the roof shapes), `fetch-osm.mjs` the OpenStreetMap highways, and the Catastro building file for 08297 is downloaded by hand into `tools/data/vallromanes/raw/catastro/` (see `knowledge.md` §3.10). [CLAUDE.md](CLAUDE.md), [spec.md](spec.md), [plan.md](plan.md) and [knowledge.md](knowledge.md) describe the design, the data and what has been measured.

## Publish it on GitHub Pages

The site is static: in the repository's Settings, Pages, choose *Deploy from a branch*, `main`, `/ (root)`. The `.nojekyll` file keeps GitHub from processing it, and every path in the page is relative, so it works under `https://<user>.github.io/slop-vallro/`.
